# <img width="25" height="25" alt="MechaLogo" src="https://github.com/user-attachments/assets/6ed09457-a6a3-4573-8cb5-9cbedbbdda9e" /> MECHA

**MECHA** is a PC software solution designed to provide technical support to thermal engineers and HVAC designers, centralizing all the calculations and tools needed for daily work in a single platform.

---

For more information, please visit the [MECHA website](www.mechautilities.com).
In addition, if you’d like to learn how to use MECHA, there are wikis available.

## Feedback and Contributions

If, while using the tool, you’d like to:

- report an issue
- suggest a new feature
- propose an improvement

you can open an **Issue** on GitHub or contact me on **LinkedIn**.

The project grows thanks to real-world use and feedback from those who use it every day. All feedback is valuable.
